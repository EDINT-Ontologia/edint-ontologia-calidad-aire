Calidad del Aire: Descripción volver a índice

Ontología para la representación de datos de calidad del aire. Reutiliza el patrón de Sensores Medioambientales para representar estaciones, sensores y observaciones de calidad del aire (NO2, O3, PM10, etc.). Reutiliza el patrón de la Ontología EDINT de Sensores Medioambientales —plataforma de sensores (edintmed:SensorPlatform), sensores medioambientales (edintmed:EnvironmentalSensor) y observaciones medioambientales (edintmed:EnvironmentalObservation)— y especializa el dominio de la calidad del aire mediante los esquemas SKOS: el tipo de sensor con SensorTypes (por ejemplo, AirQualitySensor), las propiedades observadas con SensorVariables (por ejemplo, NO2Concentration, O3Concentration o PM10Concentration) y la característica de interés con FeaturesOfInterest (por ejemplo, Air o ParticulateMatter).
